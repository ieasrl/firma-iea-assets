# Recursos de la firma corporativa IEA

Este repositorio publica las imágenes utilizadas por la firma dinámica de Exchange Online.

## Publicación

1. Subir todo el contenido de esta carpeta a la raíz del repositorio.
2. Ir a **Settings → Pages**.
3. Seleccionar **Deploy from a branch**.
4. Seleccionar la rama **main** y la carpeta **/(root)**.
5. Guardar y esperar a que GitHub muestre la URL publicada.
6. Abrir la URL de Pages y comprobar que se muestran todos los recursos.

No cambiar los nombres de los archivos después de instalar la firma en Exchange.
